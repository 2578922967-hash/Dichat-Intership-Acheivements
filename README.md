# Dichat Internship Achievements

本仓库用于沉淀我在 Dichat 实习期间的核心项目成果（投简历版），覆盖朗豪坊（Langham Place）、HSH（HIP SHING HONG）与芬名（The Fleming）等客户的社媒运营、数据分析与 KOL 合作实践。

## 项目概览

- **项目类型**：品牌社交媒体运营与增长（小红书/微信/抖音/视频号）
- **项目目标**：通过内容运营、数据监测、热点选题与达人合作，实现账号增长和业务转化
- **核心产出**：月度复盘报告、运营数据台账、KOL 数据库、内容规划表

## 关键职责与成果

### 1) 账号运营

负责客户朗豪坊、芬名多平台账号运营，覆盖小红书、微信、抖音等平台，持续超额完成阶段性指标。

- 抖音月度浏览完成率：**335%**
- 视频号月度浏览完成率：**237%**
- 小红书粉丝增长：**117%**
- 执行小红书内容发布与薯条投放，持续监控曝光、互动、涨粉、转化等指标

### 2) 竞品监测

搭建月度数据监测体系，围绕竞品与自有账号进行结构化追踪：

- 按月抓取粉丝、播放、互动等核心指标
- 输出趋势图表与阶段结论，支持运营复盘与下一周期策略
- 拆解爆款内容结构（选题、封面、标题、节奏、互动引导），沉淀素材库

### 3) 热点选题

结合 AI 工具与平台热搜信号，建立“热点池 + 选题优先级”机制：

- 按月输出可执行选题清单与机会点判断
- 融合行业趋势与品牌调性，给出落地方案
- 为内容排期、活动策划与投放方向提供决策支持

### 4) 内容规划

负责小红书与微信内容规划和生产协同：

- 基于月度选题产出内容 Demo、文案与配图分镜
- 形成可复用模板，提升出稿效率并降低沟通成本
- 从“创意-制作-发布-复盘”形成标准化闭环

### 5) KOL 合作

参与并推进 **50+** 达人合作，落地探店打卡营销活动：

- 搭建达人数据库，统一管理账号定位、粉丝画像、报价与投放记录
- 完成报价核对与合作推进，提升执行效率与可追溯性
- 月度累计实现：**浏览 12.3 万+，互动 9700+**
